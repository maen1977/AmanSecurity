# Aman Security 3.0.0 — Lightweight Local Antivirus

- Local scan cache for installed APK/split hashes and scanned files.
- Six-hour threat refresh re-checks cached SHA-256 values without re-reading unchanged files.
- Event-driven app install/update and Downloads protection retained.
- Downloads catch-up reduced from 15 minutes to 2 hours; protected-folder periodic scan reduced to 6 hours.
- Foreground protection heartbeat reduced from 1 minute to 10 minutes with a wider health window.
- Added spyware/stalkerware capability audit with false-positive-safe correlation rules.
- Permissions/privacy remain separate from malware verdicts.
- No paid/private cloud backend is required.
