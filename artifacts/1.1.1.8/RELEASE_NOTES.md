# Maen Shield 1.1.1.8

## الجودة والتحسينات

- توسعة فحص حاويات Android المضغوطة: APKS وXAPK وAPKM وAAB وAAR وJAR، مع فحص المحتوى الداخلي ضمن حدود الحجم وعدد العناصر.
- إبقاء الأرشيفات القانونية وAPK/JAR/DEX غير المعروفة خارج تصنيف التهديد المؤكد؛ لا يُعلن التهديد إلا عند وجود بصمة مؤكدة أو دليل قوي.
- تحسين فحص التنزيلات: لا تُعامل ملفات ZIP القانونية كحزم غير موثوقة تلقائيًا، ولا تُرسل سجلات SAFE المزعجة.
- إضافة بوابة تمنع تكرار إشعار الحالة نفسها خلال فترة تبريد، مع إبقاء التنبيه الجديد عند تغير الدليل أو انتهاء الفترة.
- تشديد التحديث الدوري لقاعدة التهديدات ليحترم البطارية والتخزين والشبكة، مع الإبقاء على التحديث اليدوي متاحًا.
- إزالة تحذير Kotlin من شاشة اختيار التطبيقات البنكية.
- الحفاظ على قاعدة التهديدات الموقعة والتحديث اليومي عبر GitHub Actions دون إدخال عينات خبيثة أو مفاتيح API داخل APK.

## التحقق

- `python3 tools/quality_gate.py`
- `./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease :app:bundleRelease`
- Android `minSdk=26`
- مساهمة Manus AI موثقة في تطوير وتحسين هذا الإصدار.

## تنبيه دقة

هذا الإصدار يحسن الكشف المحلي ويقلل الإنذارات الكاذبة، لكنه لا يمثل ضمانًا لاكتشاف كل تهديد واقعي. الملفات النظيفة تُخفى من التقرير، والملفات ذات المؤشرات الضعيفة تُعرض كمراجعة، والبصمات المؤكدة فقط تُرفع إلى تهديد مؤكد.
