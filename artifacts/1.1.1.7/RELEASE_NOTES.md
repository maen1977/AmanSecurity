# Maen Shield 1.1.1.7

## توسعة قاعدة التهديدات

- توسعة تجميع بصمات SHA-256 من MalwareBazaar عبر فئات Android وAPK وspyware وbanker وstalkerware وRAT وransomware وtrojan وdropper وloader وstealer وadware وbackdoor.
- استخدام metadata وSHA-256 فقط؛ لا تُنزّل عينات خبيثة ولا تُضمّن داخل APK.
- إزالة تكرار البصمات، تحديد حجم الحزمة، وتوقيع الحزمة قبل أن يقبلها التطبيق.
- استمرار استخدام ThreatFox وURLhaus وOpenPhish وFeodo Tracker ومعلومات Android Security Bulletins ضمن خط GitHub Actions الحالي.
- عزل فشل مصدر واحد عن بقية المصادر مع الاحتفاظ بآخر حزمة سليمة.

## دقة التصنيف

- تطابق SHA-256 المعروف يبقى **CONFIRMED THREAT / KNOWN_THREAT**.
- مؤشرات الروابط وC2 تُستخدم في طبقة حماية الشبكة ولا تُحوّل ملفًا محليًا إلى تهديد دون دليل مناسب.
- الأرشيفات القانونية وAPK/JAR/DEX الداخلية غير المعروفة لا تُصنّف تهديدًا لمجرد الاسم أو الامتداد.
- الإشارات الضعيفة تبقى **REVIEW** أو لا تظهر في التقرير وفق سياسة الحماية.

## الأداء والخصوصية

- لا توجد سحابة تشغيلية جديدة أو إرسال لملفات المستخدم.
- التطبيق يستقبل فهارس مضغوطة وموقعة، ويثبتها ذريًا مع حماية من الرجوع إلى إصدار أقدم.
- بقي minSdk عند 26، وبقيت الحزمة مصممة لتكون خفيفة على الأجهزة القديمة والجديدة.
